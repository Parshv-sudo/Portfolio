## 💡 KEY DECISIONS

### Question 1: Which animation library?

**anime.js:**
- ✅ Smaller bundle (16KB)
- ✅ Simpler API
- ✅ Lightweight
- ✅ Sufficient for portfolio
- 🎯 **RECOMMENDED**

**GSAP:**
- ✅ More features
- ✅ ScrollTrigger plugin (advanced scroll)
- ✅ Better for heavy animations
- ⚠️ Larger bundle (60KB)

**Decision:** Read GSAP_VS_ANIME_COMPARISON.md to decide.

### Question 2: Use both prompts together or separately?

**Together (Recommended):**
- ✅ Faster (one Claude interaction)
- ✅ Simpler process
- ✅ Guaranteed consistency
- ⏱️ ~30 minutes total

**Separately:**
- ✅ Review each stage
- ✅ Make tweaks between stages
- ✅ Modular approach
- ⏱️ ~60 minutes total

**Decision:** Use together for speed.

## 📞 SUPPORT & TROUBLESHOOTING

**If animations don't work:**
- Check browser console for errors
- Verify library loaded: `console.log(anime)` or `console.log(gsap)`
- Hard refresh (Ctrl+Shift+R)
- Try different browser

**If specific feature broken:**
- Ask Claude to focus on that feature
- Request simpler version if needed
- Check selector matches HTML

**If bundle too large:**
- Switch to anime.js (if using GSAP)
- Remove optional animations
- Use CSS for simple effects

**If performance issues:**
- Reduce animation durations in prompt
- Limit simultaneous animations
- Test on actual mobile device
